🎬 Movie Guide App

A simple Movie Guide web application that allows users to search for movies and view their details using the OMDb API.

🛠️ Technologies Used
HTML5
CSS3
JavaScript
Fetch API
OMDb API
Font Awesome

🔑 API Key

This project uses the OMDb API to fetch movie information.

For security, the API key is not included in this repository.

To run the project:

Get your own API key from the OMDb API website.
Open the JavaScript file.
Replace:
const myApiKey = "YOUR_API_KEY";

with your own API key.

📸 Project

The application provides a simple and responsive interface for searching and viewing movie information.
